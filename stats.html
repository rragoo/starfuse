Sharing and shop

How this is counted

  • No names, ids or IP addresses are stored. Each device sends only counters it keeps for the game, like “first visit 3 days ago”.
  • A player is a device: the same person on a phone and a laptop counts twice, and a private window counts as a new player each time.
  • Browsers set to “Do Not Track” are not counted. Days are in UTC.
  • A run that used “Keep going” counts once.
  • Power-ups: a run counts as using them if it used one before it first ended. Ones used after “Keep going” only add to “Times used”.
  • Saved-up coins come from each player’s first visit of the day, and a menu counts once a day per player. Coins, ads, offers, rewards and menus count from 26 Oct.
