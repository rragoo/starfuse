How it plays

Easy to start. Hard to put down.

Every run is a race against the pile. Fuse planets to make room, chain fusions for combos, and see how big you can grow before the jar fills up.

Drop

Slide to aim and lift to let go. Each planet falls, rolls and settles into the pile.

Fuse

Two of the same planet merge into the next one up. One drop can set off a whole chain of fusions.

Keep it under the line

If a planet rests above the danger line for 3 seconds, the run is over. Then it’s one more go.
